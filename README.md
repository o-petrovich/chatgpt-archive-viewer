# ChatGPT Archive Viewer v3

## Середня колонка

Є два режими:

### Зміст

Показує пункти з `topics.json`.

Поки за замовчуванням:

```text
Огляд чату
```

### Питання

Показує всі user-повідомлення:
питання, команди, посилання, код, короткі репліки та вкладення.

Довгі записи скорочуються приблизно до 130 символів,
але слово не обрізається посередині.

Клік по пункту прокручує повний чат до відповідного повідомлення.

## view.py

HTTP server тепер завжди віддає каталог,
де фізично лежить сам `view.py`.

## Запуск

```bash
python3 view.py
```
